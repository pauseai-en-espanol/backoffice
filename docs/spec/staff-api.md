# Staff API

The HTTP contract between the staff web app (and the bot's webhook) and `apps/api`. Everything here answers only on
the staff host, under `/api`, and every query runs in the caller's `withActor` transaction, so the database decides
again what they may see and do ([ADR-0002](../adr/0002-authorization-and-data-protection.md)).

## Conventions

- **JSON only**, bodies of at most 64 KB (a CSV import: 1 MB). A field a route doesn't take is refused (`400`).
- **Writes come from the staff app:** every method but `GET` needs `Origin` to be the staff origin, or `403`.
- **Errors** are `{ "error": <code> }`, sometimes with `field` or `constraint`. The staff app shows each in words
  (`packages/i18n`, `errors`). Codes: `signIn` (401, no aal2 session), `forbidden` (403), `notFound` (404),
  `invalid` (400, maybe `field`), `limit` (429), `stale` (409), `taken` (409), `linked` (409), `incomplete` (422),
  `unavailable` (503, not configured), `unexpected` (500), and the route-specific ones below.
- **Ids** are uuids; audit and timeline cursors are strings. Dates are `YYYY-MM-DD`; instants ISO 8601 with offset.
- **Contact details** (emails, phones) appear only in a person's own page and the admin's export, never in lists.

## M1: onboarding

A **person summary**, as lists show one:

```json
{
  "id": "…",
  "name": "Ana",
  "fullName": "Ana Ejemplo",
  "stage": "new",
  "owner": { "userId": "…", "displayName": "…" },
  "province": "…",
  "nextAction": "Llamar el jueves",
  "nextActionDue": "2026-10-20",
  "reasons": ["unassigned"],
  "inCommunity": true,
  "sources": ["airtable"],
  "createdAt": "…"
}
```

`name` is the preferred name, else the full name. `owner` may be null. `reasons` are the attention reasons
(`packages/domain`, `ATTENTION_REASONS`), in order.

### Intake

| Route                                                                                                     | Does                                                                                                                                                                                                                                                                                                                                            |
| --------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET /api/candidates?name&phone&email&province`                                                           | Añadir rápido, as you type: `{ candidates: [{ personId, name, stage, owner, exact }] }`; `400 invalid { field }` for a phone or email that isn't one                                                                                                                                                                                            |
| `POST /api/intake` `{ name, phone?, email?, province?, town?, chat?, note?, stage?, decision?, target? }` | Quick-add: `201 { intakeId, status, personId }`. `stage` is `to_triage`, `new` (default), `welcomed` or `active`. `decision` is `new` or `attach` (with `target`), when the person saw the candidates. `status`: `created`, `attached`, `conflict` or `review`                                                                                  |
| `GET /api/bandeja`                                                                                        | `{ items: [{ id, source, status: 'review' \| 'conflict', name, province, town, reportedBy, createdAt, candidates: [summary], person: summary \| null, conflicts: { [field]: { current, proposed } } }] }`. | `POST /api/bandeja/:id` `{ decision, target? }`                                                           | `review`: `attach` (one of the candidates), `new` or `discard`; `conflict`: `apply` or `keep`. `200 { status }`                                                                                                                                                                                                                                 |
| `GET /api/imports`                                                                                        | `{ imports: [{ id, kind, startedAt, finishedAt, startedBy, counts }], airtable: { configured, lastRun } }`                                                                                                                                                                                                                                      |
| `POST /api/imports/airtable`                                                                              | Runs the Airtable sync now: `200 { counts }`; `409 running`; `503 unavailable` (no link configured); `502 airtable { reason }` (the view couldn't be read, or its columns changed)                                                                                                                                                              |
| `POST /api/imports/csv` `{ csv, mapping?, apply }`                                                        | Without `apply`: `{ columns, mapping, preview: [first 20 mapped rows], invalid: [{ row, field }], counts }`, a dry run whose counts are what applying would do. With `apply: true` and a `mapping`: `{ counts, importId }`. `mapping` maps a column to `name`, `preferredName`, `email`, `phone`, `province`, `town`, `chat`, `note` or `stage` |

### The forms app's routes

`apps/forms` reaches the API inside the cluster only, never through the gateway. Every call carries the shared secret
in `X-Backoffice-Forms-Token` (compared in constant time) and the visitor's address in `X-Forwarded-For`, as the
gateway gave it to the forms app; the API counts submissions per address. Both run as `pauseai_backoffice_public`.

| Route                                                                                                                                                                                                                                                                             | Does                                                                                                                                                                                                                                                           |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `POST /public/census/form` `{ token? }`                                                                                                                                                                                                                                           | `{ options: [{ id, kind: 'skill' \| 'interest', label }], greeting: string \| null, link: 'generic' \| 'personal' \| 'invalid', wordingVersion }`                                                                                                              |
| `POST /public/census/submit` `{ token?, startedAt, website, answer: { name, preferredName?, email?, phone?, province?, town?, languages?, options?, skillsOther?, interestsOther?, availability?, howHeard?, pronouns?, consentEmail, consentWhatsapp, consentPrivacy, ageOk } }` | `200 { outcome: 'created' \| 'updated' \| 'review' }`; `400 { error: 'invalid', field }`; `409 { error: 'invalidLink' }`; `429 { error: 'limit' }`. `website` is the honeypot (must be empty) and `startedAt` the form's load time (at least 3 seconds before) |
