# Runbooks

What to do, step by step, when something rare happens. Each runbook says who acts, what they run, and what they
should see.

- [Deploying](deploying.md): the first deploy on the cluster, what each milestone turns on, and rotating
  secrets.
- [The first admin](first-admin.md): the owner's account creation, once, after the first deploy.
- [A lost authenticator](lost-authenticator.md): checking who asks, then the owner's reset.
- [Rotating the bot's token](rotating-the-bot-token.md): the Telegram bot's token and webhook secret, together.
- [Importing an outreach campaign](importing-an-outreach-campaign.md): from the `outreach` repo, once, dry run
  first.
