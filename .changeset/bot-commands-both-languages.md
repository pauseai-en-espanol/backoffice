The bot's commands in English with Spanish names that work the same (PLAN R38): `/joined` (`/alta`), `/left`
(`/baja`), `/mine` (`/mios`), `/unassigned` (`/libres`), `/search` (`/buscar`), `/sync` (`/sincronizar`), `/help`
(`/ayuda`), `/cancel` (`/cancelar`). The API sets Telegram's command menu on every start, by the English names and,
for Spanish Telegram, by the Spanish ones, described in Spanish; replies name a command by both names.
